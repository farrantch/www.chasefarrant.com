Navigation
  ls [path]         List directory contents
  cd <path>         Change directory; ~ home, .. parent
  cat <file>        Print a file
  less <file>       Page through a file; / search, q quit

Portfolio
  open <path|url>   Print a link from a .url file, PDF, or URL
  browse            Switch to the web portfolio
  welcome           Print the login banner
  reboot            Reset VM; discard session files

Reference
  commands [--all]  List tools; --all includes all applets
  help keys         Keyboard shortcuts
  help session      Shell, storage, networking
  help games        Games and controls
  <command> --help  Command options
