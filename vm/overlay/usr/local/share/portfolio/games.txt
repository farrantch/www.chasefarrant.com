Launch
  games / nbsdgames   New BSD Games menu
  mines               Minesweeper
  sudoku              Sudoku
  battleship          Battleship
  snakeduel           Snake duel
  checkers / reversi  Board games
  tetris              vitetris
  2048                Slide and merge tiles

Controls
  New BSD Games       Enter accepts name; arrows + Enter select
  In game             ? or ! help; q quit
  tetris              Select 1-Player Game; options list controls
  2048                Arrows or WASD move; q, then y quits
  Ctrl+C              Interrupt game; return to shell

Files
  /opt/nbsdgames/bin  Full game list; programs installed under /opt
  Scores              /var/opt or home; reset on reboot or reload
