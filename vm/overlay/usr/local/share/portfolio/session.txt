Runtime
  User      guest (uid 1000)
  Shell     BusyBox ash; flags may differ from GNU tools
  Tools     commands lists installed tools; no package manager

Storage
  Writable  Home directory and /tmp
  Lifetime  RAM only; reload, close, or reboot discards changes
  Browse    Pauses the VM; Terminal resumes it

Networking
  Guest     No network access; curl, wget, and ping are offline
  Browser   open prints links handled by the host browser

Reset
  reboot    Start a fresh VM as guest
