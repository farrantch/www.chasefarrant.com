Shell
  Tab                    Complete command or path
  Up / Down              Command history
  Ctrl+L                 Clear screen
  Ctrl+C                 Interrupt process (no selection)
  Shift+Tab              Move focus out of the terminal

Clipboard
  Ctrl+C / Ctrl+Shift+C  Copy selection
  Ctrl+V / Ctrl+Shift+V  Paste
  Cmd+C / Cmd+V          Copy / paste on macOS

Pager / editor
  less: Space            Next page
  less: /                Search
  less: q                Quit
  nano: Ctrl+O, Enter    Save
  nano: Ctrl+X           Exit
