chasefarrant.com browser Linux image

All assets are served locally. Exact binary hashes and download locations
are recorded in vm/assets.json in the website source repository:
https://github.com/farrantch/chasefarrant.com

SeaBIOS and VGA BIOS supplied by v86:
https://github.com/copy/v86/tree/5f9a90f/bios
https://www.seabios.org/

The initramfs overlay, guest startup scripts, shell helpers, and generated
portfolio files are in this website's vm/overlay and scripts directories.
The external initramfs overlays the original image at boot; the vendored
kernel image is unmodified.

Terminal font: JetBrains Mono, served locally from /fonts/.

Included license texts: BIOS-COPYING.LESSER (the license file supplied in
v86's firmware directory) and LINUX-GPL-2.0.txt (also applicable to BusyBox).

GNU nano 9.2, GPL-3.0-or-later:
https://www.nano-editor.org/dist/v9/nano-9.2.tar.xz
The unmodified corresponding source is included as nano-9.2.tar.xz beside
this file. The build recipe and dependency list are nano-Dockerfile and
nano-build-packages.txt, also in vm/programs/nano in the website repository.
Compiled as a static i586 executable with Alpine Linux 3.23.6, musl 1.2.5,
and ncurses 6.5 (20251123). See NANO-GPL-3.0.txt, MUSL-LICENSE.txt, and
NCURSES-LICENSE.txt. Upstream library sources:
https://musl.libc.org/releases/musl-1.2.5.tar.gz
https://distfiles.alpinelinux.org/distfiles/v3.23/ncurses-6.5-20251123.tgz
Alpine package recipes:
https://gitlab.alpinelinux.org/alpine/aports/-/tree/3.23-stable/main/musl
https://gitlab.alpinelinux.org/alpine/aports/-/tree/3.23-stable/main/ncurses

Curl 8.22.0, curl license (MIT-style):
https://curl.se/download/curl-8.22.0.tar.xz
